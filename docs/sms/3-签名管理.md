# 接口列表

## 1\. 创建签名

### 1.1 接口说明

> 接口地址：[https://smssh.253.com/sms/v2/signature/create](https://smssh.253.com/sms/v2/signature/create) 通用接口说明详见 [API 调用说明](https://doc.chuanglan.com/docs/I58861JUE7A3QRU4)

### 1.2 请求参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| productType | String | 是 | 产品类型：`notify`\-通知短信；`market`\-营销短信；`verify`\-验证码短信；`2ec`\-CS 短信（二类电商）；`finance`\-DK 短信（金融）；`game`\-BK 短信（游戏）；`acquisition`\-HK 短信（拉新）。 | `notify` |
| signType | String | 是 | 签名类型：`1`\-企业名称；`3`\-商标；`4`\-其他（如政企）。 | `1` |
| signName | String | 是 | 签名名称：长度为 2～18 个字符。 | \- |
| signatureSceneType | Integer | 是 | 关联资质用途：`3`\-自用；`4`\-他人。 | `3` |
| endCustomerId | String | 是 | 资质 ID | \- |
| sbjScreenshotImg | String | 否 | 国家商标局官网查询结果截图：[截图示例](https://static2.253.com/document/2026-04/6VO4AG0BIA45FWFA.png)，Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| trademarkAuthImg | String | 否 | 商标持有人出具的授权书：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| institutionImg | String | 否 | 组织机构代码截图：[查询地址](https://www.cods.org.cn/cods/dmcx/index.html)，[截图示例](https://static2.253.com/doc-center/20260803/37d7eab2-1821-4799-a756-df60557dd559.png)，Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| additionalAttachmentsImg | List<String> | 否 | 补充材料：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB，最多 9 张。 | \- |

### 1.3 请求示例

```json
{
  "productType": "notify",
  "signType": "1",
  "signName": "创蓝科技",
  "signatureSceneType": 3,
  "endCustomerId": "123456"
}
```

### 1.4 响应参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| code | String | 请求状态码：`000000` 表示成功。 | `000000` |
| msg | String | 提示信息：Unicode 字符编码，需自行解码。 | \- |
| requestId | String | 请求 ID | \- |
| data | Object | 返回数据 | \- |
| \-signId | String | 签名 ID | \- |
| \-existedSignId | String | 已存在的签名所对应的签名 ID：签名已存在时返回。 | \- |

返回数据示例（JSON）：

```json
{
  "code": "000000",
  "msg": "签名新增成功",
  "data": {
    "signId": "100001",
    "existedSignId": null
  }
}
```
