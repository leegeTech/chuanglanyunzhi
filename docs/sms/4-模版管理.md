# 接口列表

## 1\. 创建模板

### 1.1 接口说明

> 接口地址：[https://smssh.253.com/sms/v2/template/add](https://smssh.253.com/sms/v2/template/add) 通用接口说明详见 [API 调用说明](https://doc.chuanglan.com/docs/I58861JUE7A3QRU4)

### 1.2 请求参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| productType | String | 是 | 产品类型：`notify`\-通知短信；`market`\-营销短信；`verify`\-验证码短信；`2ec`\-CS 短信（二类电商）；`finance`\-DK 短信（金融）；`game`\-BK 短信（游戏）；`acquisition`\-HK 短信（拉新）。 | `notify` |
| content | String | 是 | 模板内容：不包含短信签名和退订语，长度不超过 500 个字符；包含链接时需在链接前后各加一个空格；变量用 `{s}` 标识。 | \- |
| contentName | String | 是 | 模板名称：长度为 2～20 个字符。 | \- |
| signName | String | 是 | 关联签名名称 | \- |
| businessCategory | String | 是 | 业务大类：从 [查询模板类型枚举](#template-type-enum) 接口获取。 | \- |
| businessSubcategory | String | 是 | 业务细类：从 [查询模板类型枚举](#template-type-enum) 接口获取。 | \- |
| variableParams | String | 否 | 变量属性：`Object[]` 序列化后的 JSON 字符串；每个元素的字段见 [variableParams 参数](#template-add-variable-params)；运营商建议 3 个变量，最大不超过 20 个。 | \- |
| guideUrl | String | 否 | 引流链接：`Object` 序列化后的 JSON 字符串；字段见 [guideUrl 参数](#template-add-guide-url)。 | \- |
| guidePhone | String | 否 | 联系方式：`Object[]` 序列化后的 JSON 字符串（支持多个联系方式）；每个元素的字段见 [guidePhone 参数](#template-add-guide-phone)。 | \- |
| needUnsubscribe | String | 否 | 退订语：`0`\-不需要；`1`\-需要（营销必填）。 | `0` |
| remark | String | 否 | 备注内容：描述对审核者的提议，有利于加速模板审核。 | \- |

#### variableParams 参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| name | String | 否 | 变量名称：例如变量 1、变量 2。 | \- |
| type | String | 否 | 变量类型：从 [查询模板类型枚举](#template-type-enum) 接口获取。 | \- |
| length | String | 否 | 变量长度：最大值为 `30` 位。 | \- |
| position | Integer | 否 | 变量位置：第一个变量为 `0`，第二个为 `1`，第三个为 `2`，以此递增。 | \- |

#### guideUrl 参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| guideType | String | 否 | 引流链接类型：从 [查询模板类型枚举](#template-type-enum) 接口获取。 | \- |
| content | String | 否 | 引流链接内容：需与实际下发链接一致，详见下方[填写示例](#guideUrl-content-example)。 | \- |
| domainExample | String | 否 | 完整链接示例：除了填写引流链接外，还需要提供一个完整链接示例，运营商审核需要（是短链的话，就填写完整的短链）。 | \- |
| icpImg | String | 条件 | 域名 ICP 备案截图：[查询地址](https://beian.miit.gov.cn/)，Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB；当 `guideType=2`（域名类型）时必填。 | \- |
| originLinkAuthImg | String | 否 | 原链接授权书：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| redirectLinkAuthImg | String | 否 | 跳转后链接授权书：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |

> **补充说明**：`content` 需与实际下发链接一致，不同场景的填写示例如下：

| 场景 | 模板内容示例 | 链接填写建议 |
| --- | --- | --- |
| 有协议头，无变量 | 你好...请点击： [https://api.253.com/OMVKA2v](https://api.253.com/OMVKA2v) 拒收请回复R | `https://api.253.com/OMVKA2v` |
| 有协议头，含变量 | 你好...请点击： [https://api.253.com/{s}](https://api.253.com/%7Bs%7D) 拒收请回复R | `https://api.253.com/` |
| 无协议头，无变量 | 你好...请点击： tatx.cc/OMVKA2v 拒收请回复R | `tatx.cc/OMVKA2v` |
| 无协议头，含变量 | 你好...请点击： tatx.cc/{s} 拒收请回复R | `tatx.cc/` |
| 纯域名链接（实际下发域名后无任何路径） | 你好...请点击： [https://api.253.com](https://api.253.com/) 拒收请回复R | `https://api.253.com` |

#### guidePhone 参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| guideType | String | 否 | 联系方式类型：从 [查询模板类型枚举](#template-type-enum) 接口获取。 | \- |
| content | String | 否 | 联系方式内容：模板内容中包含的联系方式（引流号码不要带空格或横杠，如 021-123-456 需填 021123456）。 | \- |
| phoneMaterialImg | String | 否 | 引流号码材料：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |

### 1.3 请求示例

```json
{
  "productType": "verify",
  "content": "您的验证码是{s}，请勿泄露。",
  "contentName": "验证码模板",
  "signName": "创蓝253",
  "needUnsubscribe": "0",
  "businessCategory": "1",
  "businessSubcategory": "101",
  "remark": "登录验证码",
  "variableParams": "[{\"name\":\"变量1\",\"type\":\"code\",\"length\":\"6\",\"position\":0}]"
}
```

### 1.4 响应参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| code | String | 请求状态码：`000000` 表示成功；其他值表示失败。 | `000000` |
| msg | String | 提示信息：Unicode 字符编码，需自行解码。 | \- |
| requestId | String | 请求 ID | \- |
| data | Object | 返回数据 | \- |
| \-templateCode | String | 模板 ID | \- |

返回数据示例（JSON）：

```json
{
  "code": "000000",
  "msg": "成功",
  "data": {
    "templateCode": "100001"
  }
}
```

## 3\. 模板列表
