## 业务参数校验错误明细（190004）

以下错误统一返回 `Code: 190004`，通过 `Msg` 字段区分具体原因：

| Msg 内容 | 说明 |
| --- | --- |
| templateId 不能为空 | 未传模板ID |
| templateId{xxx}不存在 | 模板ID未找到对应模板 |
| phoneNumbers 不能为空 | 未传手机号 |
| 签名传参{xxx} 与模板关联签名 {yyy} 不相同 | 传入签名与模板绑定签名不一致 |
| 最多支持1000个手机号 | 手机号数量超限 |
| templateParamJson 解析异常 | 变量参数JSON格式错误 |
| templateParamJson 解析无数据 | 变量参数为空 |
| phoneNumbers与templateParamJson 数量不匹配 | 手机号与变量参数数量不一致 |
| 该模板不支持变量参数 | 非变量模板传了变量参数 |
| 变量模板未传递变量参数 | 变量模板未传变量参数 |
| uid 长度不应超过256 | 外部请求ID超长 |
| report请传 true 或 false | Report参数值不合法 |
| 扩展码仅支持X位内数字 | 扩展码格式不合法 |
| 所有手机号或参数均不合法 | 全部手机号或参数校验失败 |
