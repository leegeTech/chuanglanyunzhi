# 概述

调用[短信发送](https://doc.chuanglan.com/docs/4KGLSB1T76BPH1NW)接口时 `report` 传 `true`，平台异步推送短信状态回执。

# 推送说明

推送方式：`HTTP POST`

推送地址：优先使用发送短信时指定的 `callbackUrl`；未传该参数时，使用 API Key 上配置的回调地址（统一应用管理 -> 回调设置）

数据格式：JSON

# 推送参数

## 顶层参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| ID | String | 推送事件 ID：用于标识本次推送，无业务含义，无需解析。 | \- |
| EventCode | String | 事件类型：`SMS_REPORT`\-状态回执；`SMS_MO`\-上行报告。 | `SMS_REPORT` |
| CreatedAt | String | 推送时间：格式 yyyy-MM-ddTHH:mm:ss.SSS+时区。 | \- |
| X-Custom-TraceId | String | 自定义的请求追踪标识：对应请求头中的 `X-Custom-TraceId`，请求中携带则原样返回，未携带则不返回该字段。 | \- |
| Data | Object | \- | \- |

## Data 参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| receiver | String | 自定义推送参数：可用作推送鉴权用户名，最大长度 16 个字符；需联系创蓝技术支持配置，未配置时为空字符串 `""`。 | \- |
| pswd | String | 自定义推送参数：可用作推送鉴权密码，最大长度 32 个字符；需联系创蓝技术支持配置，未配置时为空字符串 `""`。 | \- |
| mobile | String | 接收短信的手机号码 | \- |
| status | String | 运营商返回的短信接收状态（接收成功只有一个状态：`DELIVRD`，其余失败状态请前往 [code.253.com](https://www.chuanglan.com/receiptcode) 查看）。 | `DELIVRD` |
| statusDesc | String | `status` 对应的中文解释：明文。 | \- |
| notifyTime | String | 创蓝平台收到运营商推送状态回执的时间：格式 yyMMddHHmmss。 | \- |
| reportTime | String | 运营商返回的状态更新时间：格式 yyMMddHHmm，其中 yy=年份的最后两位（00-99）。 | \- |
| msgid | String | 消息 ID：对应发送接口响应中的 `data.msgId`，32 位纯数字。 | \- |
| length | String | 下发短信计费条数：纯数字。 | \- |
| uid | String | 对应发送接口请求中的 `outId`：请求中传入则原样返回，未传入则不返回该字段。 | \- |

# 推送示例

```json
{
  "ID": "evt_20260323100000_001",
  "EventCode": "SMS_REPORT",
  "CreatedAt": "2026-03-23T10:00:00.000+08:00",
  "Data": {
    "receiver": "",
    "pswd": "",
    "mobile": "13900000000",
    "status": "DELIVRD",
    "statusDesc": "消息发送成功",
    "notifyTime": "241104172820",
    "reportTime": "2411041728",
    "msgid": "24073116453300902203000007708373",
    "length": "1",
    "uid": "321abc"
  }
}
```

# 响应要求

接收方需及时返回以下响应表示接收成功：

```json
{
  "clcode": "000000",
  "msg": "接收成功"
}
```
