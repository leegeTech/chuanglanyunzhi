# 概述

手机用户回复短信后，平台异步推送该回复内容。

# 推送说明

推送方式：`HTTP POST`

推送地址：API Key 上配置的回调地址（统一应用管理 -> 回调设置）

数据格式：JSON

# 推送参数

## 顶层参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| ID | String | 推送事件 ID：用于标识本次推送，无业务含义，无需解析。 | \- |
| EventCode | String | 事件类型：`SMS_REPORT`\-状态回执；`SMS_MO`\-上行报告。 | `SMS_MO` |
| CreatedAt | String | 推送时间：格式 yyyy-MM-ddTHH:mm:ss.SSS+时区。 | \- |
| X-Custom-TraceId | String | 自定义的请求追踪标识：对应请求头中的 `X-Custom-TraceId`，请求中携带则原样返回，未携带则返回空字符串 `""`。 | \- |
| Data | Object | \- | \- |

## Data 参数

| 名称 | 类型 | 描述 | 示例 |
| --- | --- | --- | --- |
| receiver | String | 自定义推送参数：可用作推送鉴权用户名，最大长度 16 个字符；需联系创蓝技术支持配置，未配置时为空字符串 `""`。 | \- |
| pswd | String | 自定义推送参数：可用作推送鉴权密码，最大长度 32 个字符；需联系创蓝技术支持配置，未配置时为空字符串 `""`。 | \- |
| mobile | String | 终端回复短信的手机号码 | \- |
| notifyTime | String | 创蓝平台收到运营商推送的时间：格式 yyMMddHHmmss。 | \- |
| moTime | String | 终端回复短信的时间：格式 yyMMddHHmm，其中 yy=年份的最后两位（00-99）。 | \- |
| msg | String | 终端回复的内容：明文。 | \- |
| extend | String | 扩展码：对应发送接口请求中的 `smsUpExtendCode`，未传入则返回空字符串 `""`。 | \- |
| destcode | String | （已废弃）无实际用途，请忽略此字段。 | \- |
| spCode | String | （已废弃）无实际用途，请忽略此字段。 | \- |

# 推送示例

```json
{
  "ID": "evt_20260323100000_001",
  "EventCode": "SMS_MO",
  "CreatedAt": "2026-03-23T10:00:00.000+08:00",
  "X-Custom-TraceId": "",
  "Data": {
    "receiver": "",
    "pswd": "",
    "mobile": "13900000000",
    "notifyTime": "241104161450",
    "moTime": "2411041614",
    "msg": "您好",
    "extend": "123",
    "destcode": "106851410103946",
    "spCode": "106851410103946"
  }
}
```

# 响应要求

接收方需及时返回以下响应表示接收成功：

```json
{
  "clcode": "000000",
  "msg": "接收成功"
}
```
