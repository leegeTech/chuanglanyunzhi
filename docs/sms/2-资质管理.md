# 接口列表

## 1\. 创建资质

### 1.1 接口说明

> 接口地址：[https://smssh.253.com/sms/v2/qualification/add](https://smssh.253.com/sms/v2/qualification/add) 通用接口说明详见 [API 调用说明](https://doc.chuanglan.com/docs/I58861JUE7A3QRU4)

### 1.2 请求参数

| 名称 | 类型 | 必填 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| productType | String | 是 | 产品类型：`notify`\-通知短信；`market`\-营销短信；`verify`\-验证码短信；`2ec`\-CS 短信（二类电商）；`finance`\-DK 短信（金融）；`game`\-BK 短信（游戏）；`acquisition`\-HK 短信（拉新）。 | `notify` |
| enterpriseName | String | 是 | 企业名称 | \- |
| unifiedSocialCreditCode | String | 是 | 统一社会信用代码 | \- |
| legalName | String | 是 | 法人姓名 | \- |
| attentionLine | String | 是 | 经办人姓名 | \- |
| attentionIdCard | String | 是 | 经办人身份证号 | \- |
| phoneNum | String | 是 | 经办人手机号 | \- |
| identityType | String | 否 | 经办人类型：`1`\-法人；`2`\-经办人。默认值为 `2`。 | `2` |
| endType | String | 否 | 签名实名使用方：`1`\-自用；`2`\-他用。默认值为 `2`。 | `1` |
| shareType | String | 是 | 共享范围：`0`\-此账号；`1`\-所有主子账号。 | `0` |
| businessLicenseImg | String | 是 | 营业执照图片：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| legalNationalEmblemIdentityImg | String | 是 | 法人身份证国徽面：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| legalFigureIdentityImg | String | 是 | 法人身份证人像面：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| agentAuthorizationLetterImg | String | 条件 | 经办人授权书图片：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB；当 `identityType=2` 时必填。 | \- |
| nationalEmblemIdentityImg | String | 条件 | 经办人身份证国徽面：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB；当 `identityType=2` 时必填。 | \- |
| figureIdentityImg | String | 条件 | 经办人身份证人像面：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB；当 `identityType=2` 时必填。 | \- |
| identityOfficePhotoImg | String | 否 | 经办人办公场景照片：Base64 编码，支持 PNG、JPG、JPEG 格式，大小不超过 2 MB。 | \- |
| contractOtherFile | List<String> | 条件 | 终端合同照片：Base64 编码，数量 ≤ 20 个，PDF ≤ 5 MB / 图片 ≤ 2 MB；当 `endType=2` 时必填。 | \- |
| remark | String | 否 | 备注 | \- |
