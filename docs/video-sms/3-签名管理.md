# 一、创建签名

-   **接口url:** [https://rcs.253.com/videosms/api/v2/sign/add](https://rcs.253.com/videosms/api/v2/sign/add)

-   **Content-Type：** application/json

-   **请求方式:** json 格式封装的字符串，采用 post 方式提交请求

-   **编码格式：** utf-8

> 完整公共请求头、CheckSum 验签算法统一参考：[API调用说明](https://doc.chuanglan.com/docs/CC1W9RJF5RZU3OJ6)

# 说明

创建签名接口。签名内容如未带【】，系统会自动包裹。

# 请求体 body

| **参数名称** | **参数类型** | **是否必填** | **描述** | **示例** |
| --- | --- | --- | --- | --- |
| sign | String | 是 | 签名内容（可不带【】，系统会自动添加） | 上海地阳 |
| customerCode | String | 是 | 所属客户编码：1 党政军 2 民生 3 医疗器械/药店 4 电商 5 沿街商铺(中小) 6 教育培训 7 房地产 8 游戏 | 4 |
| industryCode | String | 是 | 行业属性编码（见附录行业代码表） | 17 |
| signCategory | String | 是 | 签名分类 1企业名称 2 app 3 商标 4其他(如政企) | 1 |
| signType | String | 是 | 签名类型：0 非商标类；1 商标类 **0（非商标类）**：营业执照(必填)、授权委托书(必填) **1（商标类）**：营业执照(必填)、授权委托书(必填)、商标注册证(必填)、商标授权书(选填) | 1 |
| businessName | String | 否 | 企业名称 | 上海地阳科技有限公司 |
| creditCode | String | 否 | 统一社会信用代码 | 91310115... |
| handledbyName | String | 否 | 经办人姓名 | 张三 |
| relevantIdcard | String | 否 | 经办人身份证号 | 310115... |
| body | Object | 是 | 签名素材体（以下文件均支持 source=1 base64 或 source=2 url） | 见下方嵌套参数 |
| → authorizeFile | List | 否 | 商标授权文件列表（最多 5 个,选填） | 见 SignMaterialParam |
| → entrustFile | Object | 是 | 委托书文件（最多 1 个） | 见 SignMaterialParam |
| → jobPermitFile | Object | 是 | 营业执照文件（最多 1 个） | 见 SignMaterialParam |
| → softnessFile | List | 条件 | 商标注册证文件列表 （最多 5个,signType=1 商标类时必传） | 见 SignMaterialParam |

## SignMaterialParam（素材参数）

| **参数名称** | **参数类型** | **是否必填** | **描述** | **示例** |
| --- | --- | --- | --- | --- |
| source | String | 否 | 素材来源：1 base64（默认） 2 url | 2 |
| type | String | 是 | 素材格式，如 jpg、png、pdf 等 | jpg |
| content | String | 是 | 素材具体内容：base64 字符串或 url 地址 | [http://253-assets](http://253-assets/)... |

# 二、签名审核结果推送

-   **推送方式：** POST，创蓝服务器主动推送至用户配置的回调地址

-   **Content-Type：** application/json

-   **编码格式：** utf-8

# 说明

签名审核状态变更推送。对方接收到签名状态后需要返回：**"ok"**（直接返回字符串 ok）。

# 推送参数

| **参数名称** | **参数类型** | **描述** | **示例** |
| --- | --- | --- | --- |
| accountId | String | 账号 id | 256995 |
| signId | String | 签名 id | 1762686661960269824 |
| status | Int | 审核状态：1 审核中 2 审核成功 3 审核失败 | 2 |
| remark | String | 审核备注 | 审核成功 |
| cmccStatus | String | 移动审核状态：0 不可用 1 可用 | 1 |
| cuccStatus | String | 联通审核状态：0 不可用 1 可用 | 1 |
| ctccStatus | String | 电信审核状态：0 不可用 1 可用 | 0 |
| pushUrl | String | 推送地址 | [https://rcs.253.com/videosms/api/msg/callback\_cl](http://rcs-dev.cm253.com/rcs/api/msg/callback_cl) |

# 推送示例

```Plain
{
    "accountId": "256995",
    "cmccStatus": "1",
    "ctccStatus": "0",
    "cuccStatus": "1",
    "pushUrl": "http://rcs-dev.cm253.comhttps://rcs.253.com/videosms/api/msg/callback_cl",
    "remark": "审核成功",
    "signId": "1762686661960269824",
    "status": 2
}
```

> ⚠️ 对方接收到推送后需要返回字符串 "ok"
