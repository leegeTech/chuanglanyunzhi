# 短信发送

-   **接口url:** [https://rcs.253.com/videosms/api/v2/template/send](https://rcs.253.com/videosms/api/v2/template/send)

-   **Content-Type：** application/json

-   **请求方式:** json 格式封装的字符串，采用 post 方式提交请求

-   **编码格式：** utf-8

> 完整公共请求头、CheckSum 验签算法统一参考：[API调用说明](https://doc.chuanglan.com/docs/CC1W9RJF5RZU3OJ6)

# 说明

用于提交视频短信的模板发送。支持静态模板（手机号列表）和动态模板（带变量）两种发送方式。

# 请求体 body

## 静态模板发送

| **参数名称** | **参数类型** | **是否必填** | **描述** | **示例** |
| --- | --- | --- | --- | --- |
| submitNo | String | 是 | 提交号，客户端提供，作为客户端的提交标识，长度不超过 32 位 | 202009221649 |
| phoneNumbers | String | 是 | 手机号列表，静态模板发送时此字段必填 | \["18918416998", "13381728253"\] |
| templateId | String | 是 | 模板 id | 126701341765533703 |

## 动态模板发送

| **参数名称** | **参数类型** | **是否必填** | **描述** | **示例** |
| --- | --- | --- | --- | --- |
| submitNo | String | 是 | 提交号，客户端提供，作为客户端的提交标识，长度不超过 32 位 | 202009221649 |
| phoneNumberJson | List | 是 | 动态模板变量列表，动态模板发送时此字段必填 | \[ { "phone": "18551473662", "v1": "赵联通", "v2": "测试 3", "v3": "测试 4", "v4": "测试 5", "v5": "测试 6" }, { "phone": "16601722151", "v1": "赵移动", "v2": "测试 3", "v3": "测试 4", "v4": "测试 5",
"v5": "测试 6"
}
\]

| → phone | String | 是 | 手机号 | 18551473662 |
| → v1 ~ v5 | String | 否 | 变量值，对应模板中的 ${v1} ~ ${v5} | 赵联通 |
| templateId | String | 是 | 模板 id | 1410869910296330240 |

# 接口响应

## 响应体 body

| **参数名称** | **参数类型** | **描述** | **示例** |
| --- | --- | --- | --- |
| code | String | 返回码 | "102000" |
| msg | String | 错误描述 | "请求成功" |
| requestId | String | 请求id | 32位uuid |
| data | Object |  |  |
| → errPhone | String | 提交失败的号码 | \["187179501591"\] |
| → submitNo | String | 提交号 | 202009221649 |
| → batchId | String | 批次号，一次提交算一个 | 1445638435275804672 |

# 请求示例

## 静态模板发送

```Plain
{
    "submitNo": "202009221649",
    "phoneNumbers": ["18918416998", "13381728253", "18551473662", "16601722151", "187179501591"],
    "templateId": "126701341765533703"
}
```

## 动态模板发送

```Plain
{
    "submitNo": "202009221649",
    "phoneNumberJson": [
        {
            "phone": "18551473662",
            "v1": "赵联通",
            "v2": "测试 3",
            "v3": "测试 4",
            "v4": "测试 5",
            "v5": "测试 6"
        },
        {
            "phone": "16601722151",
            "v1": "赵移动",
            "v2": "测试 3",
            "v3": "测试 4",
            "v4": "测试 5",
            "v5": "测试 6"
        }
    ],
    "templateId": "14108699"
}
```

# 响应示例

```Plain
{
    "code": "102000",
    "msg": "请求成功",
    "requestId": "32位uuid",
    "data": {
        "errPhone": ["187179501591"],
        "submitNo": "202009221649",
        "batchId": "1445638435275804672"
    }
}
```
