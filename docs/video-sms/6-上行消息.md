# 一、上行消息推送

-   **推送方式：** POST，创蓝服务器主动推送至用户配置的回调地址

-   **Content-Type：** application/json

-   **编码格式：** utf-8

# 说明

用户回复的消息推送。接收方需要返回 **"ok"**（直接返回字符串 ok）。

# 推送参数

| **参数名称** | **参数类型** | **描述** | **示例** |
| --- | --- | --- | --- |
| accountId | String | 账号 id | 167475 |
| codeNo | String | 端口号 | 0004 |
| codeNoAddress | String | 端口号地址 | 1065086140390004 |
| createTime | Long | 创建时间（毫秒时间戳） | 1606745282003 |
| msgId | String | 消息 id | 173579743935856640 |
| phone | String | 手机号 | 18717950159 |
| upContent | String | 上行回复内容 | 好的，来自晓白 |
| batchId | String | 批次号 | 1412651215151221 |
| submitNo | String | 提交号 | 637e904rd9hf |

# 推送示例

```Plain
[
    {
        "accountId": "167475",
        "codeNo": "0004",
        "codeNoAddress": "1065086140390004",
        "createTime": 1606745282003,
        "msgId": "173579743935856640",
        "phone": "18717950159",
        "upContent": "好的，来自晓白",
        "batchId": "1412651215151221",
        "submitNo": "637e904rd9hf"
    }
]
```

> ⚠️ 对方接收到推送后需要返回字符串 "ok"

# 二、上行消息拉取

-   **接口url:** [https://rcs.253.com/videosms/api/v2/reply/pull](https://rcs.253.com/videosms/api/v2/reply/pull)

-   **Content-Type：** application/json

-   **请求方式:** json 格式封装的字符串，采用 post 方式提交请求

-   **编码格式：** utf-8

> 完整公共请求头、CheckSum 验签算法统一参考：[API调用说明](https://doc.chuanglan.com/docs/CC1W9RJF5RZU3OJ6)

# 说明

开通此接口功能后，上行消息保存时间为 **72 小时**；数据拉取成功后服务器会删除当前拉取成功的数据，不再保存！请用户及时存储。

# 请求体 body

本接口无业务请求参数，鉴权通过请求头AppId实现。

| **参数名称** | **参数类型** | **是否必填** | **描述** | **示例** |
| --- | --- | --- | --- | --- |
| 无业务入参 | — | — | 接口仅需传递公共请求头，请求Body传空JSON对象 `{}` | — |

# 请求示例

```Plain
{}
```
